# 面向脑机接口申请的项目说明

## 项目名称

**基于 EEGNet 的跨被试运动想象脑电少样本适配**

## 我想解决的问题

脑机接口模型在训练被试之间通常存在明显差异。一个模型在源被试上训练完成后，面对没有参与训练的新被试，能否只使用每类少量标注样本完成快速适配？我把问题具体化为：每类只有 1、3、5 或 10 条校准试次时，更新分类头、更新整个网络，或增加轻量通道调制，哪种方案在准确率和适配成本之间更合理？

## 我做了什么

- 以 Lawhern et al. (2018) 的 EEGNet 设计为结构起点，使用时间卷积、深度空间卷积和可分离卷积处理 EEG 的时空特征。
- 在 BNCI2014-001 / BCI Competition IV 2a 的 9 名被试上建立了真实数据流程，包括下载、预处理、被试划分、训练、少样本适配和离线预测。
- 在单次训练中固定目标测试会话，不用它早停；整个项目已有查看测试后的探索选择；所有适配方法从同一个源模型和同一批校准样本开始。
- 比较无适配、分类头微调、全模型微调、逐通道缩放/偏移和 CSP+LDA。
- 保存原始试次 ID、配置、数据哈希、代码快照、逐试次预测和模型重载检查，使结果能够审计和重算。

## 当前结果

在每类 10 条校准样本的探索性实验中，9 名目标被试的平均准确率为：无适配 43.88%，分类头微调 48.44%，全模型微调 47.06%，通道缩放/偏移加分类头 48.56%。结果支持“少量标注可能改善跨被试泛化”，但没有支持“增加通道仿射参数一定优于简单分类头”。

这个结论对我很重要：我没有只保留最高分，而是同时记录负迁移、适配时间和参数量，并把仿射方案降级为消融。当前真实模型总参数为 2,464，其中源训练阶段可训练参数为 2,420；早期 1,020 参数模型只属于合成数据演示。

## 我从项目中学到的研究方法

1. 先区分论文结构借鉴、严格复现和自己的扩展问题。
2. 把最终测试集隔离，使用源域开发任务选择适配配置。
3. 不把随机种子误当成独立被试，按被试计算成对差值。
4. 同时评价准确率、Macro-F1、Kappa、参数量和适配时间。
5. 对失败运行和退化检查点保留记录，而不是只展示成功结果。

## 当前局限与下一步

目前项目仍是单数据集上的探索性研究，独立 CPU 环境已跑通早期配置 smoke test；完整矩阵重建、更多重复划分和外部数据验证还需要补充。下一步将优先完成论文配置与工程配置的严格分离，使用源域模拟新被试选择适配超参数，并报告成对置信区间和多重比较校正后的统计结果。
